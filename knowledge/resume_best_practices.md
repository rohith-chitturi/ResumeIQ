# Resume Best Practices

## Structure
1. Always start with a summary if you have more than 5 years of experience.
2. Order sections: Experience, Education, Skills, Projects (for juniors, Education before Experience).
3. Use bullet points, never paragraphs, for job descriptions.

## Content (The XYZ Formula)
- Describe what you did (X).
- Measure it (Y).
- Explain how you did it (Z).
- Example: "Improved API latency (X) by 40% (Y) by implementing Redis caching (Z)."

## Keywords
- Tailor keywords exactly to the job description without keyword stuffing.
- Use strong action verbs (e.g., "Architected", "Engineered", "Orchestrated", instead of "Worked on").
